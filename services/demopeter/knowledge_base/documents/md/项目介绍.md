# szpeter2026 知识库 - 项目介绍

## 项目简介

szpeter2026 是一个基于 RAG（检索增强生成）技术的本地知识库管理平台，兼具**文档知识管理**和**代码项目索引**两大能力。支持断点续传式大规模文件扫描，崩溃后自动恢复，无需从头开始。

## 核心功能

### 1. 文档管理
- 支持 PDF、Markdown、TXT、Word 等多种格式
- 批量导入和智能分块（保留段落/章节边界）
- 文档状态追踪和版本管理

### 2. RAG 智能问答
- 基于 Chroma 向量数据库的语义检索
- 混合搜索：向量 + FTS5 全文检索 RRF 融合
- DeepSeek 和 Ollama 双 AI 模式
- 流式输出和来源追溯

### 3. D 盘代码索引（D-Indexer）
- 自动扫描 22 个 D 盘项目目录，提取代码文本
- 支持 30+ 种编程语言和配置文件格式
- 语义搜索："那个做跨境电商的项目在哪"
- **断点续传扫描**：崩溃/断电后自动从中断处恢复
- **文件缓存加速**：增量扫描时跳过未变更文件（10-100x 提速）
- 每日凌晨 3 点定时增量扫描

### 4. Web 管理面板
- 实时统计仪表盘
- D 盘索引导航（断点状态、扫描进度、代码搜索）
- 文档管理界面
- 流式对话界面
- 报告生成中心

### 5. 报告系统
- 日报：每日知识库使用统计
- 周报：每周增长趋势分析
- 月报：月度总结和展望

## 技术架构

项目采用 Python + Flask + SQLite + Chroma 的轻量架构：

- **数据层**：SQLite (WAL 模式) 存储元数据、查询日志、断点状态、文件索引缓存
- **向量层**：ChromaDB PersistentClient 本地模式，无需 Docker
- **AI 层**：DeepSeek API 或 Ollama 本地模型，一键切换
- **展示层**：Flask Web 面板 + Jinja2 模板 + RESTful API

### 断点续传机制

```
扫描文件 → 处理完一个目录 → 保存 checkpoin (SQLite)
    ↓ 崩溃
重启 → 读取 checkpoin → 跳过已完成目录 → 继续扫描

文件缓存: (path, size, mtime) 三元匹配 → 直接跳过
```

## 设计原则

1. **轻量优先**：零配置启动，单文件 SQLite 数据库即可运行
2. **模块解耦**：Scanner / Checkpoint / Indexer / Scheduler 各组件独立可替换
3. **弹性容错**：断点续传保证长时间任务不丢失进度
4. **隐私友好**：支持完全本地化运行，代码数据不出本机
5. **易于扩展**：标准 API 接口，插件化架构
