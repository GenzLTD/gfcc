# 真人会实验 · 第一场（建圈 → 复盘）

> 目的：用一场最小真人会验证围坐三判据 ——
> 1. **记得住**：散会后过段时间能召回当时的圈与结论（证据链引用）；
> 2. **有共识**：结论有合意引擎的 `consensus_score` 与 `participants` 支撑；
> 3. **兑得现**：会上承诺的贡献有 `capability_trace` 可回溯。
>
> 方式：全程走 `POST /v1/ask` 信封（`message` 自然语言 + `context.port_hint`），
> 每步以**端口证据**为准，不靠口头复述。

## 前置条件

- gfcc_kernel 已在跑（`/health` 返回 `status=ok`）。
- 3 名具名真人：jason（主持人）、A、B；各自用自己的 `session_id`（会话隔离）。
- LLM 可用（`/health` 的 `llm` 为 ollama 或等效）。

## 实验步骤

全程 `POST http://127.0.0.1:5211/v1/ask`，请求体结构：

```json
{
  "message": "<自然语言指令>",
  "context": {"port_hint": "<端口>", "session_id": "<本人>"}
}
```

| # | 步骤 | message（示意） | port_hint | 端口证据 | 验收标准 |
|---|---|---|---|---|---|
| 1 | 建圈 | `创建围坐圈 第一场` | `circle` | 响应 `data.circle_id` | 圈落库，3 人都拿到同一 `circle_id` |
| 2 | 入座 | jason/A/B 各自 `我是<本人>，加入围坐圈` | `identity` | `identity` record（sub 落库） | `identity.list_active` 见 3 人 |
| 3 | 议题入库 | 发起人 `记住议题：<议题文字>` | `memory` | 响应 `data.id`（记忆 record id） | 记入七库，抄下 id 备用 |
| 4 | 协商 + 拍板 | 主持人 `讨论议题并形成结论` | `consensus` | `consensus_summary` + `consensus_score` + `participants` | score ≥ 阈值（默认 85），3 人都在参与者里 |
| 5 | 贡献兑现 | 每人 `我完成了<承诺事项>` | `contribution` | `fulfilled:true` + `identity.capability_trace` | 判据3：贡献兑得现 |
| 6 | 散会抄 id | 记录员 `本次结论：<结论文字>，记入七库` | `memory` | 新 record id | 结论可回溯（判据2 证据链起点） |
| 7 | 复盘 | 隔日 A `回忆上次围坐的结论` | `memory` | 返回引用上次 record id | **判据1 记得住**：答案包含步骤 6 的 id/结论 |

## L3 加分项（`GFCC_MODE=profile.demo` 时）

- 步骤 4 前先 `POST /v1/knowledge/query {"question":"..."}` 查知识库，
  把 demopeter 输出作为协商参考证据，随议题一并存入 memory record；
- agentmemory_iii（gateway 3210）接管记忆后，步骤 7 的 recall 走语义召回。

## 判定规则

- **过**：步骤 7 真的引用了步骤 6 的 id（记得住），步骤 5 的 `capability_trace` 真实（兑得现），
  步骤 4 的 `consensus_score` 达到阈值（有共识）。
- **不过**：任何一步靠口头"我以为"带过、没有端口证据 —— 直接记入"实验失败记录"，
  注明是哪一判据/哪一步断了，作为下一场实验的输入。
