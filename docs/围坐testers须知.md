# 围坐 testers 须知（一页）

一场 60～90 分钟的同步会。真人入座，不是开发联调，也不是付费会员。人齐、场次公布后才开；没收到主持人通知前不用进站操作。

**这场不是测 PlanetX / 测评 / 知识库。** 说话可以用腾讯会议；系统只记「拍板那一句」和「谁本人点了头」。验收查记录 id，不回放录像。

**这里不是聊天室。** 视频里说的都不算；只有轮到你（持发言权）才能写那一句；入座的人要**本人点头**，旁观不能点。库里留下的共识记录才算数。

---

## 你要做的三件事

1. **报名认领席位**（下表）。这是这场分工，不是产品里的职业皮肤。
2. **开场领自己的号**。主持人为每人发入口和令牌；**不要转给别人、不要两个人共用、不要自己去 curl 注册。** 没有独立身份就无法证明本人点确认。
3. **用这个号做席位上那几下**（建圈 / 加入 / 写拍板句 / 点确认 / 兑现）。系统内可对拍板句提交异议（必填理由）或撤回；观点不必只在视频里说。

散会后主持人按「报名真人 ↔ 令牌 `sub` ↔ 记录 id」核对。对不上或代点，本场作废。

---

## 席位（报名时认领一个）

每人一个席位。A 可以兼 D。开发/管理员不能顶替 A/B/C。

| 席位 | 这场你要做的事 |
|------|----------------|
| **A 圈主** | 建一个真议题圈（不要叫「测试圈」）、提出议题、认定别人的贡献 |
| **B 对端** | 加入这个圈，认真看议题，**你本人**点确认（不要让别人代点） |
| **C 旁观** | 先只看；有实际参与痕迹后再升级，不是管理员点一下 |
| **D 主理** | 把承诺的贡献兑现掉（没有独立 D 时由 A 兼） |

报名回复：

```
姓名（或昵称）：
认领席位：A / B / C / D
能同步在线的时间：周几 + 时间段（至少连续 90 分钟）
联系：微信或邮箱
```

满 **4 人**（下限 3 人：A 兼 D）且时间能对上，主持人才公布场次和入口。

## 时间与会场

- 时长：**60～90 分钟**一整场。商量用视频即可；拍板那几分钟按主持人指引在系统里点。
- 具体钟点：报名后协调，**以主持人群内通知为准**。
- 现在不用自己找网址试。入口和令牌主持人当场发。
- **不是这场会场**：产品主页测评、匹配页 `/ppi`、付费页、知识库 `:5220`、腾讯旧站 `http://1.14.202.161/`（已冻结冷备）。生产站 `http://14.29.216.219/` 是另一条产品线，未经主持人允许不要当围坐入口。

## 场次当天（主持人带跑，照做即可）

1. **入座**：A 建圈，B 加入，C 先旁观。
2. **提议**：A 把商量后的拍板写成一句（例如「本月怎么分工」），写清背景。
3. **确认**：A 和 B **各自用自己的手**点确认。AI 不能代点；不能只给自己认定贡献。
4. **留下痕迹**：下一件事引用刚才那条共识（证明记得住）。
5. **兑现**：A 认定 B 做了什么；A 或 D 把承诺兑现掉。
6. **可选**：C 凭这场实际痕迹升级，不要找人「给个权限」。

本场不做：申诉、解散圈子、改规则、上链、开通会员。
