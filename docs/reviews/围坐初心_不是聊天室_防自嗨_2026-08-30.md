## 1. 机制上不是聊天室，要承认表面像

匿名树洞 / 4chan 一类的本质：自由发言 + 去责任化 + 消息流。产出是「一群人说了话」，没有东西被决定、被记录、被追溯。

围坐和它的差异是三件**硬件**，不是换一套皮肤：

| 硬件 | 做什么 | 消灭聊天室的哪一刀 |
|------|--------|-------------------|
| 发言权纪律 | 只有持地板者能写拍板句；其他人 ack 或旁观 | 插话、刷屏、谁嗓门大谁算数 |
| 双向确认 | 入座成员本人 ack 才 `consensus_verified`，带 `verified_at`、acks、证据链 | 「说了就算」；vision 判据 2：证据链 100% 可追溯 |
| 角色与记录 | A 组织 / B 参与 / C 旁观（旁观不能点头）；圈态落库、可复盘 | 流水消息、过了就没了 |

**要承认的相似处**：C 旁观约等于潜伏；短 `sub` 约等于昵称；UI 也是打字窗口。只看「人聚在一起打字」，确实分不出区别。入场时用一句话说清即可，不必把界面做成「不像聊天」来自证。

联合国笔记里的「辩论 ≠ 表决」，和下面 Git 的「Conversation ≠ Merge」是同一刀。

## 2. 自嗨不自嗨：三条硬指标（不是「像不像聊天室」）

清单已经写过：本地双机互打、开发号互 ack、管理员拨角色，**一律不算内测开始**。联邦纪律：不得把管道层成功说成围坐层得分。

| # | 指标 | 2026-08-30 的诚实答案 |
|---|------|----------------------|
| 1 | 有没有真人在真实场景用它做出一个**真决策**？ | **没有。** jason 是人；tester-b / tester-c 是占位；助手旁观不算 party。pytest 165、上云冒烟、旁观在场可见，全是 smoke。这是自嗨嫌疑的真正来源。 |
| 2 | 价值是否闭环？ | 会场只稳定覆盖「协商得了」的**前半**（本人 ack → verified）。记得住（`refs`）、兑得现、人往高处走都还没接上。管道通 ≠ 价值兑现。 |
| 3 | 痛点是否为真？ | 「说完等于没讨论、结论不可追溯、少数人控场」作为推断是真的，**还没有被一场真实会议验证**。在被验证前它是假说。 |

方向上不是自嗨：差异是机制性的，不是套壳。历史上没有同款「地板 + 全员本人 ack + 可追溯记录」当聊天室卖。

阶段上如果迟迟不开一场**具名真人**会，它就是自嗨：迄今几乎所有「证据」都来自自己人。防自嗨的尺子早就在 vision 与清单里，缺的是执行。

**人齐门禁没有齐。** 齐的是工程侧（补丁 3、HS256、落库、场次间纪律）。G2 具名真人空着。不要写成「门禁都齐了只差招人」——门禁的主体就是人。

## 3. 和 GitHub 协作像在哪、学什么

像在「什么东西算数」，不像在「大家一起打字」。GitHub 可学的不是 Issues 闲聊，是：**主线受保护，改动必须变成一条可合并的提案，有人审查，留下可 diff 的历史。**

| Git | 围坐 |
|-----|------|
| 本地改、开分支 | 视频里商量（还不算数） |
| 开 PR | 持地板写拍板句 |
| required reviewers | 入座 `parties` 本人 ack |
| 围观 PR、不能 Approve | C 旁观 |
| Merge 进 main | `consensus_verified` |
| `git log` / SHA | 提案 id、acks、证据链 |
| 下一个 PR 引用 SHA | 判据「记得住」的 `refs`（尚未接上） |

聊天室停在说话即产物。Git 与围坐都把说话当成 **merge 之前的草稿**。

**学**：合并才是事实；保护主线、一次一条；审查名单写死；历史即产品；人审与自动检查分开；第二人必须看（不要提议人自动 ack 冒充本人确认）。

**不要学**：把评论区做成第二聊天室；多数 Approve 代替全员 ack；用挂一周的异步 PR 当 90 分钟围坐的默认节奏；匿名随手 fork。

更近的参照：Gerrit 的 +1/+2、Rust RFC 的 FCP——先讨论，再进入「只差正式点头」的窗口。

价值链上，学 Git 最该补的下一刀仍是 **`refs`（下一步基于哪次 merge）**，不是 D 类会务按钮。
