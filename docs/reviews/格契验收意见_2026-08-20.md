## 四、额外加固（评审未要求，主动补上，加分）

1. **五条成功判据全部可度量**——不是口号，每条都引用了契约字段（`refs` 复用率、`score_evidence` 追溯率、`fulfilled`→`capability_trace` 闭环、角色跨越证据、AI 证据占比上限）。
2. **AI 红线写进字段级**——`circle.invariants`「AI 不是投票成员」、`consensus`「parties 必须是人」、`memory`「AI 不得 supersede / 不得静默改写」、contribution 新增不变量「治理权不可买卖」。
3. **README 将"实现画像"与"契约真源"解耦**——现在的 HTTP demo（Tatha/DemoPeter/iii）被明确标注为可卸载画像，避免新人把 demo 当脊柱。
4. **变更流程闭环**——「过 L-1 → 改 JSON → 改提纲 → 改代码」+ CHANGELOG 记录，契约演进有了纪律。
5. **版本一致性**——8 份契约统一 1.1.0，deprecated 别名（`intent`、`method`）按策略保留一个次版本，无悬空。
