## 3. 商业价值（不是「只有实验」）

**结论**：品类是真的，本季还不是一门生意。

卖的是共同体把事**谈成、做成、记在人身上**的操作系统（Tractor：你掌方向，我出力气），不是聊天 Bot。可收费的合法切口：托管配额、实施与带跑、营造师培训、可替换实现——档位只管配额，**不卖治理权**。Tatha 免费/Basic/Pro 是旁边求职·测评线，testers 须知写死：付费页不是围坐门票。

仓里没有付费 circle、没有格契合同。08-28 现场圈曾议「品牌筹备上架」和开店预算（商标等约 2 万）——那是品牌与商店徽章，与「会场能不能当应用来用」不是同一条关键路径。

## 4. 和 Discord 像在哪、不像在哪

**像（可学）**：核心动作不该先买票。Server Boost = 给整场升级配额，付钱的人买不到更值钱的一票。对应 ethos「档位不是身份」。

**不像（不要抄成主业）**：Discord 卖的是待着、说话、开黑，收入大约七成 Nitro。格契卖的是拍板、本人确认、认定、兑现。Discord 后半段的付费身份组，踩在「治理权不可买卖」上。

说话的地方像 Discord；把话说成可执行决议更像 Loomio。围坐须知已把说话放在视频会、把拍板句放进内核——Discord 占会场前半截，不是账本。

## 5. 「Discord 那种上架商品」差多少

尺子要分开，否则会按错误工期排期。

| 尺子 | 含义 | 差距 |
|------|------|------|
| **A. Discord 级常驻应用** | 多端客户端、自助开号、应用内语音视频、推送、7×24 | 品类不同。现网约一张手机网页，估 **~5%** 该品类产品面 |
| **B. 可上架的围坐伴侣** | HTTPS、邀请打开即入座、说话仍可外挂会议；加到主屏幕仅 iOS/Android | **数周级**（有现成域名且备案过时），不是数年 |

## 8. 为何「自助 / 套壳 / 小程序」会倒逼账号（建议 = D3）

内核现状：没有用户名密码表。票里的 `sub` 就是人。密钥不在浏览器里，**自助领号 = 伪造或公开签发**。记忆按 `sub` 隔离；一人多号可搬运记忆、伪造「多人同意」。一人一票目前只能靠主持人按报名表签发。

放开自助须先有账号体系。拆成两条，不要捆：

| 线 | 是什么 | 何时 |
|----|--------|------|
| D3-A 会话账号 | 邮箱 / 微信 / 验证码登录；令牌降成会话（Loomio） | 另立项；内核 README「何时放开自助」指这条 |
| D3-B 华为静默登录 | 元服务 Account Kit：UnionID/OpenID；设备已登录华为账号；无登录/注册 UI | **仅元服务**；与 D3-A 不是同一套；做元服务账号时单独立项 |

| 做法 | 如何倒逼 |
|------|----------|
| 页上自助开号 | 直接取消主持人签发 |
| 套壳送审 App Store | 审核默认「下载即开号」 |
| 先做微信小程序 | 默认 OpenID |
| 元服务接 Account Kit | 不是邮箱逻辑；是 D3-B |

当前减负只做邀请深链，签发权仍在密钥持有人。

## 10. 风险项（切 D1 前要处理的）

### R1 安全（优先）— URL 与会话

**现况校准**：施工单已规定 JWT **不进 URL**；`?i=` 是 16 位 Crockford 兑换码，一次性，库只存 hash。redeem 后身份 JWT 在 **`sessionStorage`**（关标签即清）。

仍不够：兑换码会进 nginx access log、浏览器历史、Referer、微信转发/截图；默认邀请有效期与 token 同为 **天级**（不是分钟级）；`sessionStorage` 可被同源 XSS 读走。泄漏兑换码 ≈ 在过期前冒名入场；泄漏 JWT ≈ 冒名 + 读该 `sub` 记忆。

**补丁（不改 D1 方向，建议切 testers 域名之前做完或并行）：**

1. nginx 对 `/circle/` 的 `i=` query **脱敏**（§0.1 第 4 条）。  
2. 邀请码 TTL 收到 **分钟～数小时**（场次窗口），不要默认 30 天。  
3. 中期：redeem 后改发 **HttpOnly + Secure Cookie** 会话，JWT 不进 JS 可读存储。

### R2 合规 — 备案硬门禁

见 §7。废除「testers 私发链接可在备案完成前跑」作为对外 HTTPS 的豁免。

### R3 回滚

切流后 IP 入口保留。回滚动作：云上签发改回 `--invite-base http://14.29.216.219/circle/`；testers 须知改回 IP；子域 DNS/vhost 可暂停不删。稳定期天数拍板时填（建议 ≥ 7 天）。
