## v2 改版说明（2026-08-27 实地勘察后废止 v1）

v1 方案 = 腾讯 Nginx 反代到天翼 + 停腾讯本机 Looma。勘察后废弃，改为：

- **天翼 = 唯一生产入口 + 门面**：PlanetX / T-space 静态站落地天翼，浏览器直接访问天翼。
- **腾讯 = 原地冻结全量冷备**：容器 / 数据 / 静态 / 配置**全部保留、不做任何改动**。

废止理由（均为实地证据）：

1. 天翼 `/`、`/tspace/` 原为 `return 404`（§8.4「静态站不落地天翼」的落地形态）。v1 反代后腾讯 `/` 会拿天翼的 404，DoD 浏览器抽查必挂。
2. 腾讯反代 = 引入「腾讯 Nginx 挂 → 天翼入口跟着挂」的中间故障点；直连天翼 IP 链路最短、故障面最小。
3. 腾讯 ingest 钥匙**全盘 grep 零命中** → 腾讯即使被老入口访问，也只是本地服务旧数据，**不会**向内核发 beacon，无双脑写污染，冷备语义天然成立。

四台角色（本单动天翼的静态 + **阿里的 API 指向迁移**；Vultr 只确认；腾讯不动）：

| 机器 | 角色 | 本单做什么 |
|------|------|------------|
| 天翼 `14.29.216.219` | **唯一大脑 + 唯一门面**（已绿） | 静态站（PlanetX / T-space）落地 + Nginx 补静态 location；其它勿动 |
| 腾讯 `1.14.202.161` | 大陆入口 → **原地冻结全量冷备** | **不动**（容器 / 数据 / 静态 / 配置全保留；ingest 钥匙已证为空） |
| 阿里 `47.115.168.107` | 内容/官网终端 | **API 指向迁移到天翼**（nginx `/v1/` 反代 + 前端 JS 硬编码去 `api.genz.ltd`，站点本体不动）；交叉链接改指 `http://14.29.216.219/` |
| Vultr / `api.genz.ltd` | 海外真人入口 | **确认**格契 ingest 为空；Stripe 可留海外 |
