> **背景**：qcc 官方调整后海外线收缩（见第 12 步），阿里内容站（WordPress 鸿蒙站 + poetries-h5 诗词站 + szbolent-portal 招聘门户）的 Looma API 原指向海外 `api.genz.ltd`（Vultr）。把 API 出口改指天翼 `14.29.216.219`（唯一大脑）。**站点本体 / DNS / 备案均不动**——阿里不装 Looma、不配 ingest，只改出口方向；阿里内容站原地保留（可当备份）。

**2026-08-27 上机勘察：**

| 项 | 实测 |
|----|------|
| 阿里 nginx live 反代（2 处） | `conf.d/00-szbolent.conf`（`default_server`，WP 系域名）+ `conf.d/szbolent-h5.conf`（www.szbolent.cn 诗词站），各 1 处 `location /v1/` → `proxy_pass http://api.genz.ltd/v1/` |
| 阿里 JS 硬编码 | `poetries-h5/dist/assets/pages-index-index.5_Z2IwG-.js`：`"https://api.genz.ltd"`（条件拼接，szbolent.cn 域名时取绝对地址，否则同源 `/v1`）；`szbolent-portal/dist/assets/{poetry,looma}-*.js`：`"http://api.genz.ltd"`（portal 当前**未挂 nginx**，仅作构建产物一并替换，防将来挂载时遗漏） |
| 天翼入口 | Nginx 80 `default_server`（`server_name _`，不校验 Host）；`/v1/`、`/health` → `127.0.0.1:5203`。Flask 业务路由全为 `/v1/*`，`/health` 无前缀；CORS 用 flask-cors 白名单（白名单外只不加 ACAO 响应头、**不 403 业务**） |
| 不动项 | `/var/www/szbolent-portal/nginx/szbolent.conf`（仓内参考文件、非 live，且指向 `139.180.184.25`）；所有 `.bak` 备份文件 |

### 第 13.1 步：阿里 nginx 反代改指天翼（2 处）

```bash
ssh root@47.115.168.107
cp /etc/nginx/conf.d/00-szbolent.conf /etc/nginx/conf.d/00-szbolent.conf.bak.20260827
cp /etc/nginx/conf.d/szbolent-h5.conf /etc/nginx/conf.d/szbolent-h5.conf.bak.20260827

# 两处 location /v1/ 统一改为指向天翼（sed 不锚行首，兼容两文件不同缩进）
sed -i -e 's#proxy_pass http://api.genz.ltd/v1/;#proxy_pass http://14.29.216.219/v1/;#' \
       -e 's#proxy_set_header Host api.genz.ltd;#proxy_set_header Host 14.29.216.219;#' \
       /etc/nginx/conf.d/00-szbolent.conf /etc/nginx/conf.d/szbolent-h5.conf

nginx -t && systemctl reload nginx
```

### 第 13.2 步：阿里前端 JS 硬编码改同源（推荐）或直连天翼

**推荐：改同源空串**——各域名 nginx 都有 `/v1/` 反代，请求走 `www.szbolent.cn/v1/` → 阿里反代 → 天翼，**无跨域、无 CORS 依赖**，域名语义不变：

```bash
cd /var/www
cp poetries-h5/dist/assets/pages-index-index.5_Z2IwG-.js{,.bak.20260827}
cp szbolent-portal/dist/assets/poetry-BWHejGob.js{,.bak.20260827}
cp szbolent-portal/dist/assets/looma-DKOC_9U8.js{,.bak.20260827}

sed -i 's#"https://api.genz.ltd"#""#' poetries-h5/dist/assets/pages-index-index.5_Z2IwG-.js
sed -i 's#"http://api.genz.ltd"#""#' \
  szbolent-portal/dist/assets/poetry-BWHejGob.js szbolent-portal/dist/assets/looma-DKOC_9U8.js

# 验证：api.genz.ltd 应全部消失
grep -c 'api.genz.ltd' poetries-h5/dist/assets/pages-index-index.5_Z2IwG-.js \
  szbolent-portal/dist/assets/poetry-BWHejGob.js szbolent-portal/dist/assets/looma-DKOC_9U8.js
```

**或直连天翼 IP**（需配合 13.3 的 CORS）：把上面两条 sed 的目标 `""` 换成 `"http://14.29.216.219"` 即可。

> 注意：assets 文件名带 hash 且 `szbolent-h5.conf` 对 `.js|.css` 配了 `Cache-Control: public, immutable`——**改内容后文件名不变，浏览器会吃旧缓存**。测试时强刷（Cmd/Ctrl+Shift+R），或把 `poetries-h5/dist/index.html` 里引用的文件名手工加版本后缀（如 `.5_Z2IwG-.js` → `.5_Z2IwG-.v2.js`）。
